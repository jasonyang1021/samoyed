# Security

Please do not commit API keys, OAuth client secrets, database credentials, downloaded source content, or private Lab profiles.

Use local `local.env` files for development. They are ignored by Git; copy `.env.example` and fill in secrets locally. If a credential may have been exposed, revoke it and issue a replacement before opening an issue.

For a suspected security issue, contact the repository maintainer privately rather than posting the credential or exploit publicly.
